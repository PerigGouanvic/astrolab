# _souffle (nom provisoire)

**Statut** : stub personnel, hébergé sous `astrolab/`, **gitignoré** (voir `astrolab/.gitignore`). Ne sera pas poussé sur `github.com/PerigGouanvic/astrolab`.

**Intention** : chantier personnel de sevrage tabagique. Passage progressif du régime actuel (6 cigarettes le matin, parfois plus, + vape continuelle) vers la **première borne : 2 cigarettes matinales + vape en diminution continue**.

**Approche** : escalier, pas franc coup. Tabac d'abord, vape ensuite.

**Pourquoi hébergé sous astrolab** : le contexte astrologique est le **levier** de ce chantier, pas un décor. En vivant sous `astrolab/`, le sevrage baigne dans la posture astrologique — thème natal, transits actuels et à venir circulent naturellement à chaque session. Symétriquement, les questions incarnées qui émergent ici peuvent nourrir en retour la conception d'astrolab.

**Origine** : cristallisé le 2026-09-19 à partir d'une conversation astrologique dans astrolab. Le contexte (Saturne à venir sur Mars-Lune natals en 2027-2028, trigone Uranus actuel, Pluton en I depuis 2023) justifie la priorité et le calendrier — voir `CLAUDE.md`.

**Anti-scope** : pas de morale, pas de méthode médicale prescrite par IA, pas de mélange avec les autres chantiers.

**Fusion potentielle** : peut devenir un cas d'usage de `_coach-sante/` à terme, mais reste séparé pour l'instant. Ce chantier est *vécu*, pas *outillé*.
